Licenciamento & Fluxo de Caixa
Efetuei o pagamento via QR Code (PIX). Como recebo a chave de ativação?
O processo é 100% automatizado. Nossa infraestrutura está integrada diretamente com a API do Mercado Pago. Assim que a transação é confirmada pelo gateway, o servidor valida o recebimento e atualiza o token de segurança local na sua máquina em tempo real. Não há necessidade de inserção manual de seriais ou envio de comprovantes por e-mail.
Posso usar a mesma licença em mais de um terminal de vendas?
As licenças padrão são vinculadas estritamente à assinatura digital da máquina (Hardware ID) para garantir a integridade dos dados locais. Caso necessite operar com caixas simultâneos compartilhando a mesma base de dados, consulte nosso plano Multi-Terminal na aba de Planos.
Arquitetura de Dados & Hardware
O sistema precisa de conexão constante com a internet?
Não. O ecossistema JC-Softwares foi projetado com engenharia de persistência local autônoma (.dat). O ponto de venda (PDV) opera de forma isolada e contínua em caso de quedas de rede. A conexão com a internet é requisitada apenas na inicialização para a rotina rápida de verificação de licença técnica.
Como funcionam as impressões de cupom e relatórios?
O sistema possui gerenciamento silencioso direto com o spooler do Windows. Se o código do documento disparado for de venda ou segunda via, o layout é formatado automaticamente em bobinas térmicas de 80mm. Se for um relatório administrativo estrutural, a saída é configurada para folhas A4, tudo executado sem exibir telas de diálogo travando a operação do operador.
