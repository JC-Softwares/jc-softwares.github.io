🔒 Segurança do Banco de Dados:
Este sistema opera de forma autônoma offline. Seu banco de dados local está camuflado e protegido contra acessos não autorizados de curiosos.

2. Ativação por Hardware ID

Para sua proteção, o software é vinculado diretamente à máquina do cliente. Siga os passos abaixo:

  • Inicie o executável: Instale o sistema e abra a tela de login inicial.
  • Copie o ID da Máquina: Localize o código gerado automaticamente (Hardware ID) exibido na janela.
  • Envie para o suporte: Encaminhe esse código para gerar sua chave exclusiva de validação.
  • Acesse o sistema: Cole a licença gerada no campo indicado para liberar o primeiro login.
